# Changelog

## 0.1.0 — 2026-09-13

Initial public source release as **EzKBBuilder**, licensed under MIT.

- Generic source-grounded knowledge cards and configurable product-document profiles.
- Direct compatible API, FastGPT App, and offline mock providers; bounded generation / audit / repair workflow.
- Persistent versions and events, interruption recovery, explicit human review, export, publication and acceptance records.
- Local embedding search and cited answers; approved and draft-test indexes; stale-version filtering and embedding cache.
- Fifty-card cross-domain evaluation scripts and aggregate results, with first-run failures and final regression scope documented.
- Chinese web workbench, English quick start, offline tests and wheel installation checks.
- Host, browser-origin, and JSON content-type checks on the local HTTP interface, with request-level regression tests.
- `ezkb-builder` command added; `knowledge-pipeline`, `knowledge_pipeline`, and `KP_` settings retained for compatibility.

The release targets local single-user use. External platform ingestion, authentication, distributed execution, PDF/Office ingestion, and large-scale retrieval remain outside this version.
