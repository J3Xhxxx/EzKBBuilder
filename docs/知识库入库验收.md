# 知识库入库验收

知识卡用于构建知识库。现阶段以“合格可用”为目标：内容有来源，能支持目标问题，重要条件和对象范围完整，资料未提供的信息不编造。措辞不必与来源一致；少量冗余不阻断入库。关键错答、漏条件、混对象和无资料却编答案应阻断入库或上线使用。

## 待执行用例

[library_faq_queries.yaml](../examples/knowledge_card_demo/library_faq_queries.yaml) 包含 10 个验收用例，来源为 [library_faq_source.md](../examples/knowledge_card_demo/library_faq_source.md)。每条提供主问题、同义问法、资料可回答性、必须保留的事实或条件、禁止断言、来源文件与原文证据点。

用例覆盖开放时间、阅读与借书的登记差异、借阅上限与期限、完整续借条件、已被预约、再次续借、未知收费、节假日、线上服务与馆址，以及星桥虚构图书室的对象范围。`answerable_from_source: false` 表示无法从资料得出所求的具体信息；合格回答应明确资料未规定。对象范围用例为 `true`，因为资料足以回答“不能推广到所有图书馆”，并不代表资料包含所有图书馆的规则。

**这份 YAML 是待执行用例，不是已有测试成绩。** 能解析 YAML 只证明文件格式可读取，不能证明知识卡已合格，也不能证明某个平台已检索成功。

## 入库前：内容是否足以回答

在一次 pipeline 生成知识卡后，检查实际生成的内容及其来源引用，而不是只看提示词中有没有规定某些字词。

1. 逐条对照主问题、同义问法和来源证据，判断知识卡是否保留了回答所需内容。无需为同义问法重复存储整段答案。
2. 检查限制条件是否跟随对应规则。续借必须保留到期前、服务台申请、一次、增加 7 天以及已被他人预约不可续借；不能只留下“可续借 7 天”。
3. 检查对象是否明确为本测试虚构的星桥图书室。读者登记、同时借阅上限等规则不能变成所有图书馆的通用规定。
4. 检查未知信息是否有明确边界。未规定逾期收费、节假日、线上服务和馆址，不能被改写为免费、照常开放、没有线上服务或某个现实地址。
5. 记录每条用例的通过、失败或待确认及原因。修复阻断问题后，重查受影响用例。

这是内容可回答性检查。它可以发现卡片漏信息、错信息及失去条件的问题，尚未验证目标知识库中的切分、检索、上下文拼接或最终回答表现。

## 入库后：实际检索与回答是否合格

只有在选定目标知识库并完成实际导入后，才能进行这一阶段。用主问题和同义问法逐项查询，保留系统真实返回的结果；不能预填命中、分数或成功状态。

建议每次执行记录以下信息：

| 记录项 | 内容 |
| --- | --- |
| 执行上下文 | 日期、目标知识库、导入内容版本及可辨认的系统配置 |
| 查询 | 用例 ID 与实际输入的主问题或同义问法 |
| 检索证据 | 实际命中的内容、可追溯的来源或片段标识；没有可见证据时如实记录 |
| 最终回答 | 系统实际回答原文 |
| 判定 | 对照必须保留的事实和禁止断言，记录通过、失败或待确认及原因 |

先确认实际提供给回答环节的证据是否足够，再确认最终答案是否正确保留条件与对象范围。对于资料可回答的问题，证据缺失或答案漏关键条件均不能算通过；对于未知信息问题，回答应承认资料不足，不能借常识补出收费、假日安排或地址。检索到一段相似文字本身不等于问答合格。

当前用例面向单张示例知识卡。一次 pipeline 生成单卡不等于已支持大文档自动分块，也不证明分块边界能保留完整条件。接入大文档时，需要另行验证拆分后的检索片段是否保留适用对象、关键限制和来源。本验收说明不表示项目已有向量数据库、真实发布适配器或完成了任何目标知识库的导入。
