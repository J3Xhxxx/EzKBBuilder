# EzKBBuilder 实施状态

更新日期：2026-09-13

| 能力 | 当前结果 |
|---|---|
| 默认知识卡 | `knowledge_card` 1.1 面向知识库入库、检索与问答；必填主题与范围、知识正文，条件和例外随对应事实就近保留。 |
| 按需结构 | 解释、示例、应用和适用边界可省略；空选填段不产生空标题；修复可删除无依据的选填段。 |
| 模板扩展 | `product_docs` 保留为可选专用模板；默认卡片不要求行业编号或固定操作流程。 |
| 示例 | 工作台默认星桥图书室业务规则/FAQ；保留跨领域演示资料，CLI 内置最小离线示例。 |
| 模型调用 | 统一 Generate、Audit、Repair 请求与错误合同，支持直接 API、FastGPT App 和离线模拟。 |
| 持久化 | SQLite 保存状态、事件、不可变版本、审核绑定、发布与验收记录、修复预算和中断信息。 |
| 工作台 | 任务状态自动同步，支持全文审核、退回原因、三格式导出、人工发布与验收反馈。 |
| 通用验收 | 按来源支撑、问题覆盖、片段可独立理解、入库检索与问答四项人工登记结果；失败项必须附带原因。保存登记不会执行真实检索。 |
| 本地检索 | Qwen3-Embedding-8B 嵌入、SQLite 索引和缓存；片段排序后展开完整卡回答；正式与待审核测试索引隔离。 |
| 实际评测 | 50 张跨领域卡、100 个检索问题、70 个问答；最终复测 Top-3 100/100、问答事实核对 50/50、无答案拒答 20/20，详见测试报告。外部知识平台未验证。 |
| 业务验收准备 | 另有10条图书室业务检索/问答用例，仍为待执行，不计入50张跨领域成绩。 |
| 回归检查 | 发布检查覆盖安装包、进程恢复、检索与版本隔离、浏览器跨站请求边界；程序回归不替代知识内容的人工验收，持续检查结果见仓库 Actions。 |
| 本地运行 | 提供 CLI、无密钥演示、环境变量示例、Windows 启动脚本、测试和架构文档。 |

离线 `mock` 仅提供来源摘录与流程演示，不执行真实 AI 内容归纳或语义审计。50 张测试使用真实 API，结果仅代表这一批官方文本来源与固定问题；最后一轮是修复后的复测，没有独立领域专家参与。新领域、模型、来源和外部平台仍需重新评估，见 [50 张测试报告](50张跨领域知识库测试报告.md)。
